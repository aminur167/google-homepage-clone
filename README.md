# Google Homepage Clone

Pixel-perfect recreation of the Google search homepage built with HTML and CSS, focusing on layout precision and styling accuracy.

## Features

- Centered search bar with focus styling
- Navigation bar with functional links
- Google logo and branding elements
- Microphone and search icons
- Footer section with links
- Responsive layout

## Files

```
index.html    - Main HTML structure
style.css     - Complete styling
google.png    - Logo asset
search.png    - Search icon
mic.png       - Microphone icon
bars.png      - Menu icon
```
